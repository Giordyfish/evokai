# Examples

Applications that use Evokai end to end. Each one runs against the [quick start](../docs/quickstart.md).

| Example | What it shows |
| --- | --- |
| [bookshop-app](bookshop-app/README.md) | A shop page with an assistant: a Node backend that mints session tokens, the `<evokai-chat>` panel, and the shop's own MCP tool |
| [bookshop-python](bookshop-python/README.md) | The same shop page and assistant with a Python backend (FastAPI) and the `evokai-client` package |
