# Code of conduct

Evokai adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project's spaces: issues, pull requests,
discussions, reviews and any other channel of the project.

In short: be respectful, assume good faith, give and accept constructive criticism, and focus on what is best for the
project and the people in it. Harassment, insults and personal attacks are not tolerated.

## Reporting

To report a behaviour that breaks the code of conduct, use GitHub's private reporting so that the report reaches the
maintainer only: open a private report at <https://github.com/Giordyfish/evokai/security/advisories/new> and start the
title with "Conduct:", or use GitHub's **Report content** on the comment or issue concerned. Reports are handled in
confidence.

## Enforcement

The maintainer applies the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban or permanent ban, depending on the impact of the behaviour.
