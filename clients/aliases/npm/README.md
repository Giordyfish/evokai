# evokai

[Evokai](https://github.com/Giordyfish/evokai) summons AI agents into any app: any model provider, your app's tools
over MCP, skills and voice, always acting as the signed-in user, within budgets.

This package re-exports the headless client, [`@evokai/evokai-client`](https://www.npmjs.com/package/@evokai/evokai-client):
`evokai/server`, `evokai/browser` and `evokai/react` are the same entry points. Ready-made Web Components are in
[`@evokai/evokai-ui`](https://www.npmjs.com/package/@evokai/evokai-ui).
