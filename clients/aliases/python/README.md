# evokai

[Evokai](https://github.com/Giordyfish/evokai) summons AI agents into any app: any model provider, your app's tools
over MCP, skills and voice, always acting as the signed-in user, within budgets.

This package installs the Python client, [`evokai-client`](https://pypi.org/project/evokai-client/), and nothing
else: `pip install evokai` and `pip install evokai-client` give you the same `evokai` module. The service itself is
distributed as a container image: see the [quick start](https://github.com/Giordyfish/evokai#quick-start).
